Privacy Policy

Last updated: 1 November 2026

This page explains what to expect when you visit the AI Buddy website or use the AI Buddy learning skill.

1. Website hosting

This is a static information website. It does not ask you to create an account or provide payment details. It is hosted by GitHub Pages. GitHub may process technical information such as request and server logs. Read GitHub’s Privacy Statement for details.

2. Using AI Buddy in ChatGPT

AI Buddy is a learning skill used within ChatGPT. Messages you send in ChatGPT are handled by OpenAI under the settings and policies that apply to your account. This website does not receive or store your ChatGPT conversations.

Read the OpenAI Privacy Policy and review your ChatGPT data controls.

3. Support requests

If you report a problem through GitHub Issues, information you submit is handled by GitHub and may be publicly visible. Do not post passwords, private medical details, account numbers, or other sensitive information in a public issue.

4. Payments and tracking

AI Buddy is intended to be free. This website does not offer purchases or collect payment details. It does not intentionally add advertising or analytics tools.

5. Changes and questions

This policy may be updated if the project changes. For questions, visit the Support page.

This policy describes the current static website and ChatGPT learning skill. If the project later adds forms, analytics, accounts, or other data collection, update this policy before using those features.
